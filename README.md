# Darwin Population Simulator

An evolutionary simulator that creates a population of individuals with varied attributes who interact through actions such as battles, conversations, walking, and resting. The system tracks the evolution of attributes and displays real-time graphs and tables showing the population’s status.

---

## Features

- Generation of individuals with random attributes (Strength, Speed, Luck, Intelligence, Dexterity, Wisdom, Charisma, Beauty).
- Daily simulation where individuals perform actions (battle, talk, walk, sleep, etc.).
- Battles that affect individuals’ HP and track kills.
- Real-time visualization using bar charts and attribute tables.
- Dynamic sorting of the population by HP.
- Unique colors to identify individuals in tables and charts.
- Displays the winner’s status at the end of the simulation.
